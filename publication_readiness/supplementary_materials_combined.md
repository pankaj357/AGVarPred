# Supplementary Materials — AGVarPred

## Supplementary Methods

### S1. ClinVar gold-standard construction

Training labels were obtained from the NCBI ClinVar `variant_summary.txt` flat file (release 31 March 2024). The following sequential filters were applied:

1. **Assembly** — keep only records with `Assembly == GRCh38`.
2. **Origin** — keep only records with `OriginSimple == germline`.
3. **Review status** — keep only the three highest review-status tiers:
   - `criteria provided, multiple submitters, no conflicts`
   - `reviewed by expert panel`
   - `practice guideline`
4. **Clinical significance** — keep only unambiguous `Pathogenic` or `Benign` labels.
5. **Conflict exclusion** — drop any record whose `ClinicalSignificance` field contained the substring `conflicting` (case-insensitive).
6. **VCF coordinates** — require non-missing `Chromosome`, `PositionVCF`, `ReferenceAlleleVCF`, and `AlternateAlleleVCF`.
7. **Deduplication** — collapse duplicate `chrom:pos:ref:alt` entries, retaining the first occurrence.

No phenotype, disease, allele-frequency, or gene-list filters were applied beyond those above. The resulting gold standard contained **134,002 unique variants** in **9,222 genes** (40,584 pathogenic, 93,418 benign).

### S2. Gene-level partitioning

Variants were split at the gene level to prevent information leakage. The procedure was:

1. Collect all unique HGNC gene symbols from the gold standard.
2. Split genes into 80% train and 20% temporary holdout using `sklearn.model_selection.train_test_split` with `random_state=42` and `stratify=None`.
3. Split the temporary holdout into 10% calibration and 10% test using the same function and seed.
4. Assign every variant to the split corresponding to its gene.

Because each gene appeared in exactly one split, there was no gene overlap between training, calibration, and test sets. Variant counts per split before feature extraction were:

| Split | Variants | Genes | Pathogenic | Benign |
|---|---:|---:|---:|---:|
| Train | 101,604 | 7,377 | 27,788 | 73,816 |
| Calibration | 16,223 | 922 | 6,537 | 9,686 |
| Test | 16,175 | 923 | 6,259 | 9,916 |

Feature extraction, model training, calibration, and internal evaluation were performed only on variants represented in the final feature matrices (train 86,378; calibration 13,201; test 12,385).

### S3. AlphaGenome feature extraction

Functional genomic scores were generated with the AlphaGenome Python SDK (version 0.6.1). For each gene:

- Input variants were formatted as a VCF-like table with columns `chromosome`, `position`, `reference_allele`, `alternate_allele`, and `gene_symbol`.
- The SDK variant scorers were invoked with the recommended variant-scorer collection and a 1 Mb reference interval centered on each variant.
- Each scored variant returned a vector of raw assay-track scores named `{output_type}__{biosample_name}__{track_name}`.
- Per-gene output matrices were written as Apache Parquet files and merged across all genes and scoring runs.

The merged raw AlphaGenome matrix contained one column per assay track. Missing values arise when a given variant class cannot be scored by a particular assay.

### S4. gnomAD allele frequency and VEP processing

Population allele frequency and VEP annotations were extracted from the gnomAD exomes release 2.1.1 liftover to GRCh38 (`gnomad.exomes.r2.1.1.sites.liftover_grch38.vcf.bgz`) using `pysam.VariantFile`.

- **Allele frequency** — the `AF` INFO field was read for each matched variant; if absent, the allele frequency was set to zero.
- **VEP annotations** — the `CSQ` INFO field contains a comma-separated list of consequence annotations across Ensembl transcripts. The first transcript was selected and parsed for:
  - SIFT prediction and score
  - PolyPhen prediction and score
  - Consequence term
  - IMPACT level
  - Loss-of-Function (LoF) flag
  - Protein position
  - Amino-acid change

These annotations were generated by gnomAD using **Ensembl VEP release 85** with **GENCODE v19**. No separate VEP re-annotation was performed.

### S5. Feature engineering

The merged feature matrix contained approximately 4,631 raw columns: one per AlphaGenome assay track plus derived VEP and allele-frequency fields.

**Numeric features**
- Missing values were imputed with the median (fold medians during feature selection; global training-set median for the final pipeline).
- All numeric features were scaled with `sklearn.preprocessing.RobustScaler` (median centering and interquartile-range scaling).

**Categorical VEP features**
- `vep_IMPACT`, `vep_SIFT_pred`, `vep_PolyPhen_pred`, and `vep_LoF` were ordinal-encoded with biologically informed severity orders:
  - IMPACT: MODIFIER < LOW < MODERATE < HIGH
  - SIFT: tolerated < tolerated_low_confidence < deleterious_low_confidence < deleterious
  - PolyPhen: benign < possibly_damaging < probably_damaging < unknown
  - LoF: LC < HC
- `vep_Consequence` was one-hot encoded.
- Missing categorical values were assigned a "missing" level and mapped to −1 after encoding.

**Derived features**
- `log10_gnomAD_AF = log10(gnomAD_AF + 1e-8)`
- `AF_missing` binary flag
- `is_ultra_rare` flag for alleles with frequency < 0.01%
- Binary indicators for missense, synonymous, stop-gained, frameshift, splice-region, and high-confidence LoF consequences

### S6. Nested feature elimination

Feature selection used nested feature elimination driven by LightGBM gain importance:

1. On each of five gene-group folds, preprocess without leakage.
2. Fit a LightGBM classifier (300 trees, seed 42, gain importance) on the training fold.
3. Select the top `n` features by gain importance.
4. Retrain a reduced model on those `n` features and evaluate AUPRC on the held-out fold.
5. Repeat for `n` in {40, 60, 80, 100, 120, 140, 160, 200, 250, 300, 400, 500, 750, 1000, 1500, 2000}.

The optimal panel size was chosen by the one-standard-error rule applied to mean cross-validated AUPRC: the smallest `n` whose mean AUPRC was within one standard error of the best observed mean AUPRC. The final selected panel contained **120 features** (111 AlphaGenome + 2 gnomAD AF features + 7 VEP-derived features).

### S7. Model training and hyperparameter optimization

The classifier was `lightgbm.LGBMClassifier`. Hyperparameters were optimized with Optuna (Tree-structured Parzen Estimator sampler, seed 42) over **100 trials**, maximizing the mean five-fold gene-group AUPRC on the training set.

Search space:

| Parameter | Range |
|---|---|
| `n_estimators` | 200–500 |
| `learning_rate` | 0.01–0.08 |
| `num_leaves` | 20–80 |
| `max_depth` | 3–8 |
| `min_child_samples` | 10–100 |
| `subsample` | 0.6–1.0 |
| `colsample_bytree` | 0.6–1.0 |
| `reg_alpha` | 1e-3–10.0 (log) |
| `reg_lambda` | 1e-3–10.0 (log) |

Class imbalance was addressed by setting `scale_pos_weight` to the benign-to-pathogenic ratio in each training fold. No early stopping or resampling was used.

The best trial (trial 64) achieved cross-validated AUPRC 0.9676 with:

| Parameter | Value |
|---|---|
| `n_estimators` | 485 |
| `learning_rate` | 0.0653 |
| `num_leaves` | 73 |
| `max_depth` | 8 |
| `min_child_samples` | 91 |
| `subsample` | 0.6013 |
| `colsample_bytree` | 0.6757 |
| `reg_alpha` | 0.0373 |
| `reg_lambda` | 0.0140 |

The final model was trained on the full training set with the 120 selected features.

### S8. Calibration and threshold selection

Raw LightGBM probabilities were calibrated with `sklearn.isotonic.IsotonicRegression(out_of_bounds='clip')` fit exclusively on the held-out calibration set. The binary operating threshold was selected by grid search over thresholds 0.05–0.95 (step 0.01), maximizing F1 on the calibration set. The full-model threshold was **0.42**; the no-allele-frequency model threshold was **0.45**.

### S9. Evaluation metrics

- **ROC-AUC** — area under the receiver-operating-characteristic curve.
- **PR-AUC** — area under the precision-recall curve.
- **MCC** — Matthews correlation coefficient.
- **F1** — harmonic mean of precision and recall at the operating threshold.
- **Brier score** — mean squared error between predicted probabilities and binary labels.
- **ECE** — expected calibration error with ten equal-width probability bins.
- **FPR** — false-positive rate on the all-benign gnomAD Common Benign benchmark.
- **Net benefit** (decision-curve analysis) — `TP/n − FP/n × p_t/(1 − p_t)`, evaluated at thresholds 0.01–0.99 in steps of 0.01.

### S10. Confidence intervals and statistical testing

**Bootstrap confidence intervals**
- Internal test set ROC-AUC: 2,000 stratified resamples with replacement.
- External benchmark ROC-AUC and MCC: 1,000 stratified resamples when sample size ≥ 20 and both classes were present.
- Stratification resampled positive and negative sets independently to preserve prevalence.
- Intervals were percentile-based (2.5th and 97.5th percentiles).

**DeLong’s test**
- Pairwise comparisons of correlated ROC curves between AGVarPred and each competitor on variants scored by both tools.
- Raw p-values were adjusted across all valid pairwise tests using the Benjamini–Hochberg FDR procedure.
- Significance threshold: q < 0.05.

### S11. SHAP interpretation

SHAP values were computed for the internal test set using the `shap` library. For interpretation:

- Per-feature mean absolute SHAP values were computed.
- Features were mapped to AlphaGenome assay categories (e.g., splicing, regulatory, transcription) and biosample tissue groups.
- Contributions were normalized within the non-AF, non-VEP feature set to report relative contribution percentages.
- The top individual feature was identified by mean absolute SHAP; tissue and assay rankings reflect availability and selection rather than causal biological drivers.

### S12. Variant-type classification

Variants were classified into mutually exclusive consequence classes using a fixed priority order on VEP consequence flags and terms:

1. stop-gained
2. frameshift
3. splice (splice_donor_variant, splice_acceptor_variant, splice_region_variant)
4. missense
5. synonymous
6. UTR
7. intron
8. non-coding exon
9. other

For external benchmarks, classes with fewer than 20 scored variants were merged into an `other` category before metric computation to avoid unstable estimates. The synonymous class contained no pathogenic variants in the internal test set, so ROC-AUC could not be computed.

## Supplementary Note 2 — External Benchmark Independence Audits

### Inclusion criteria

External benchmarks were required to satisfy **all** of the following:

1. **Zero variant overlap** with the ClinVar train/cal/test sets.
2. **Zero gene overlap** with the ClinVar train/cal/test sets.
3. **No ClinVar-derived labels**.
4. **Germline-only variation**.

Independence was verified with audit scripts that compared `chrom:pos:ref:alt` coordinates and HGNC gene symbols against the training set. `train_gene_set.json` records the 9,222 genes used for training/calibration/testing.

### Retained independent benchmarks

| Benchmark | Variants | Pathogenic | Benign | Genes | Label source | Variant overlap | Gene overlap |
|---|---:|---:|---:|---:|---|---|---|
| Humsavar | 14,718 | 1,317 | 13,401 | 5,681 | UniProt manual curation | 0 | 0 |
| MAVE Independent | 7,557 | 3,751 | 3,806 | 25 | MaveDB functional assays | 0 | 0 |
| gnomAD Common Benign | 4,989 | 0 | 4,989 | 585 | gnomAD common exonic SNVs | 0 | 0 |
| Grimm2015 Selected | 5,258 | 512 | 4,746 | 3,112 | Curated non-circular sets | 0 | 0 |
| DVD | 8,388 | 195 | 8,193 | 12 | Deafness Variation Database | 0 | 0 |

### Excluded or separately analyzed datasets

| Dataset | Reason for exclusion / separate handling |
|---|---|
| ClinVar 3-star holdout | 91.6% gene overlap and 39% variant overlap with training data |
| VIP Database | Pathogenic labels are ClinVar-derived; analyzed separately as a ClinVar-held-out-gene consistency analysis |
| Somatic cancer-hotspot panels | Not germline variation |
| Phenotype-derived de novo case/control sets | Not germline-only and/or label circularity concerns |
| Constrained-gene panels | Hundreds of genes already present in training set |
| MAVE assays for BRCA1, PTEN, etc. | Genes present in training set |

### VIP consistency analysis

The VIP Database (Baylor College of Medicine) contained 3,880 variants (1,075 pathogenic, 2,805 benign across 904 genes) after GRCh37-to-GRCh38 liftover and removal of training-set genes and variants. All pathogenic labels were derived from overlapping ClinVar annotations, so VIP was **not** treated as an independent external benchmark.
